# WhatsApp Blast Dashboard

A powerful WhatsApp broadcast platform with real-time analytics, campaign management, and Hermes automation integration.

## Features
- WhatsApp Broadcast
- Contact Management
- Campaign Management
- Real-time Analytics
- Webhook Integration
- Hermes Automation

## Tech Stack
- Backend: Fastify + PostgreSQL + Redis
- Frontend: Next.js + React + Tailwind CSS
- Queue: BullMQ
- Infrastructure: Docker + Nginx

## Quick Start
```bash
git clone https://github.com/dejenk/whatsapp-blast.git
cd whatsapp-blast
docker-compose up -d
```

See README.md for full documentation.
